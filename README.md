# 🚀 Boi Forte

> ERP pecuário de corte multi-fazenda com gestão zootécnica completa (cria, recria e engorda), controle financeiro por lote, portal do capataz, veterinário e proprietário, com app mobile offline-first para lançamentos no curral.
